# 🖐️ Virtual Keyboard Controlled by Hand Gestures

A touchless virtual keyboard application that uses hand gestures for input. It utilizes **Python**, **OpenCV**, **MediaPipe**, and **Flask** to create an intuitive and interactive experience for users.

## 🚀 Features

- Real-time hand tracking
- Gesture-based keyboard input
- Touchless typing interface
- Web interface to enable/disable the keyboard
- Customizable layout

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python, Flask
- **Computer Vision**: OpenCV, MediaPipe

## 📷 How It Works

1. The webcam captures real-time video.
2. MediaPipe detects and tracks hand landmarks.
3. OpenCV interprets gestures based on finger positions.
4. A virtual keyboard is displayed on the screen.
5. Hand gestures (e.g., index finger pointing) are used to select keys.
